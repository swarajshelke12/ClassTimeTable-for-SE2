# SE2 Timetable

A simple, fast, and mobile-friendly timetable app for **SE2 Computer Engineering** students.

---

## Features
- **Today View**: Real-time schedule with live status indicators ("Live", "Up Next") and countdown timers.
- **Full Week View**: Complete 5-day grid view across all slots and breaks.
- **Batch Selection**: One-tap filter for your specific batch (`A1`–`C3` or `ALL`).
- **AI Timetable Assistant**: Built-in chatbot to instantly ask about classes, upcoming lectures, faculty, and breaks.
- **Dark / Light Mode**: Clean, high-contrast theme toggle.

---

## How to Use
1. Open `index.html` in any web browser.
2. Select your batch pill at the top.
3. Switch between **Today**, **Full Week**, or the **Assistant** tab.
