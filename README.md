# SE2 Timetable App

## What is it?
The SE2 Timetable App is a modern, responsive web application designed specifically for Second Year Engineering (SE2) students at PICT. It provides a clean, easy-to-read, and dynamic schedule of daily and weekly classes.

## What problem does it solve?
Keeping track of college schedules can be confusing and cumbersome with static images or PDFs. This application solves this by providing:
- A dynamic **"Today View"** that highlights currently ongoing and upcoming classes.
- A **"Full Week"** grid to see the entire schedule at a glance.
- Real-time status indicators (e.g., "Happening Now", "Up Next").
- Support for both Light and Dark modes for better readability in any environment.
- Quick reference for subject directories, professor names, and color-coded subjects.

## How to use
1. **Open the app**: Simply open `index.html` in any modern web browser.
2. **Navigate**: Use the top navigation tabs to switch between the "Today View" and "Full Week" view.
3. **Check Subjects**: Tap the "Subject Directory" at the bottom to expand a legend explaining all subject abbreviations and professors.
4. **Theme Toggle**: Use the sun/moon icon at the top right to switch between light and dark themes.
